# 扩大知识覆盖，保留大模型的通用能力 · v0.6

本项目仅用于课程作业，无商业用途。本页记录 2026-10-13 的知识扩展实现与参考项目。私有教材、教材正文索引和模型密钥继续留在 `.local`，不随 GitHub 上传；获准使用的公开网页片段与项目自写导读另放在公共 JSON 中。

## 资料证据与模型一般知识

供应商大模型已有的知识与课程知识库是两层能力。模型切换只改变组织答案的模型，不会清空资料索引，也不需要为同一家供应商的不同模型反复填写 API Key。RAG 把本次问题相关的资料片段送进上下文；它不会修改模型权重，也不会让模型永久记住整本教材。

资料增强回答使用人工课程卡、授权教材原页和公开官方网页快照，并区分环境、单位、公式约定、时间和模型补充。一般知识可处理资料未覆盖的问题，明确标记未经本项目资料核验；没有证据时不编造引用。路由由网页与聊天服务实现，资料采集和入库模块本身不调用供应商模型。

主问答和原创海洋助手“小航”共享访客对话、模型和知识范围；公共网页与本地管理前端共用聊天控件。界面默认“资料 + 模型知识”（`general`），可在“更多”改为“仅依据资料”（`course`）。前者保留模型原有能力并单列资料外知识；后者普通空检索不请求模型编写缺乏依据的答案。Agent 可分析实际提供的共享模板，不等同于空检索的普通对话；回答保存本次供应商、请求模型及实际响应标识。

没有匹配资料的问题加入当前访客的待补资料记录。公网记录加密保存在访客状态内，不会公开给其他访客，也不会自动成为共享知识或触发模型训练。维护者可依据真实缺口寻找、登记有权使用的资料，再做入库与来源检查。

文本层入库页覆盖率为 1789 / 1846，约 96.9%；57 页全部为 `blank_or_short`，本次未检测到乱码或页级解析错误。这不是知识正确率、OCR 成功率或整份资料包覆盖率；原文的公式、表格、提取顺序和适用条件仍需要原页复核。课程全文索引检查保留在 [VALIDATION_V0_5.md](VALIDATION_V0_5.md)，本轮公开知识与聊天预算见 [VALIDATION_V0_6.md](VALIDATION_V0_6.md)。

继续导入资料时，可以省略 `pages` 按全部页读取文本层；清单须包含需要保留的全部来源。下面是结构示例：

```json
{
  "sources": [
    {
      "id": "S17",
      "path": "../sources/S17.pdf",
      "title": "课程教材",
      "printed_page_offset": 19,
      "page_nodes": {
        "375": ["normal_mode_field"]
      }
    }
  ]
}
```

上例只展示单个来源的配置结构；实际五来源清单保持私有。`page_nodes` 只保留经过核实的原页—概念关系；没有关系的其他页也可以通过原文检索，不需要把全书每页挂到同一个知识点。

```powershell
python backend/ingestion.py --manifest .local/kb/full-manifest.json
```

默认输出 `.local/kb/chunks.sqlite3` 和 `.local/kb/chunks.report.json`。每次运行重建清单中所有来源，清单须包含需要保留的全部来源。正文、稳定片段编号、来源编号、PDF 原页、字符范围和文件 SHA256 一起保存；SQLite 的报告元数据与正文在同一次原子替换中更新。读取文件哈希采用分块读取，避免为大 PDF 额外复制整文件。

## 已接入公开海洋知识

v0.6 已实际采集并入库 30 篇 NOAA NOS 文章正文，另有 9 条项目自写的中文参考导读，共 39 个可检索来源、67 个片段。42 项来源登记中剩余 3 项为动态数据入口，尚未接通实时数值。新内容包含海洋酸化、珊瑚白化、全球与局地海平面、海流、漂流浮标/ADCP、海啸、微塑料、Argo 质控、TEOS-10、QARTOD 和 WOA/WOD 等，已经通过中文问题实际召回测试。

NOAA 正文依据其公开使用政策保留机构、URL、原页更新、取得时间、许可和响应/正文哈希，移除导航、图片、音视频及其说明。其他机构仅提供项目自写导读和官方链接，导读不作为复制原文或官方译文。原始教材和公开网页是独立索引，网页数不加入 1789 个教材原页。图谱“学习资源”可直接点开来源和中文导读，无需模型 Key。详见 [OPEN_OCEAN_KNOWLEDGE.md](OPEN_OCEAN_KNOWLEDGE.md)。

启动与状态查询按 168 小时 TTL 检查 30 篇 NOAA 正文并调度后台刷新；9 条项目导读和 3 个数据入口由维护者更新登记。检索与状态响应只读已有快照，不等待网络。刷新有线程锁、HTTPS 主机/具体 URL 白名单、重定向检查、20 秒超时与 2 MB 大小上限；失败保留上次成功正文。后台只更新独立 `.local/kb/open-ocean/snapshot.json`，不改教材 SQLite 或开源内置 JSON。节点在线时可提供新快照；云端内置的静态包仍需导出、构建并重新部署才更新。

这属于官方清单的文档采集与刷新，不是实时全网搜索。今天取得的介绍页不等于今天的观测值；历史示例、典型值、气候态、预报和实测值须区分。CO-OPS、NDBC、海洋热含量产品的入口已登记，但数据 API 适配器尚未完成，不能据此捏造“最新”海温、海平面或波高。

## 知识点之外的原页也能进入答案

完整资料中的英文 `sound speed profile` 可以被中文“声速剖面”或 `SSP` 命中。索引和查询均做课程术语别名展开；未绑定图谱节点的原文也用等价术语检查相关性。没有实际词项匹配的片段不会因为关联边而被引入。

精确匹配的人工课程卡优先，用于保留公式和适用条件；实际匹配的原文优先于宽泛的图谱背景，避免默认八条上下文全部被邻居知识卡占满。新增原页不会自动成为已审核知识卡，仍标记为 `source_text_unreviewed`。不会自动生成或认证物理因果关系。

没有精确课程焦点的新公开主题优先保留对应公开证据，避免小预算被泛“海洋”背景占满；Munk、SSP、TL 等明确课程概念仍保留精确优先级。公开检索采用 BM25 与人工双语主题别名，未引入付费嵌入服务。

全文索引修订后自动刷新检索缓存。同一批正文的词项展开、分词、BM25 统计与词项集合一起缓存；后续问题只进行查询评分，并仅复制最终返回的片段，避免每次深拷贝数千条原文。测试覆盖 1200 个独立片段，确认缓存复用与正文修改后的刷新；这不是大型生产系统性能基准。

## 可以查看真实覆盖情况

`GET /api/knowledge/status` 保留旧字段 `cards`、`indexed_sources`、`indexed_pages`、`chunks`、`needs_ocr`，并增加：

| 字段 | 含义 |
| --- | --- |
| `source_coverage` | 每个来源的编号、标题、总页数、选中页、处理页、成功页、片段和失败分类；不返回文件路径 |
| `coverage.total_pages` | 这批已登记 PDF 的实际总页数；无法确定时为 `null` |
| `coverage.selected_pages` | 本次选中处理的 PDF 页数；省略 `pages` 即选中整份 PDF |
| `coverage.processed_pages` | 已尝试提取的原页数，包括没有形成片段的页 |
| `coverage.indexed_pages` | 至少形成一个可检索片段的唯一原页数 |
| `coverage.failed_or_needs_ocr_pages` | 未形成片段、需要 OCR 或人工查看的数量 |
| `coverage.blank_or_short_pages` | 文本层为空或过短的页；可能是封面，也可能是扫描内容 |
| `coverage.unreadable_pages` | 乱码或页级解析错误 |
| `coverage.coverage_ratio` | 成功入库原页 / 资料总页数 |
| `coverage.selected_success_ratio` | 成功入库原页 / 本次选中页数 |

“选中页全部成功”不等于“整本资料都已检索”。DOCX、TXT 和 Markdown 没有稳定 PDF 页码，不能伪造总页数；其 `processed_units`、`indexed_units` 表示实际文本输入是否处理成功。旧索引没有总页数报告时保留 `null`，不猜覆盖率。

v0.6 增加 `public_ocean` 和 `web_sources`：分别报告公开登记数、可检索来源数、成功正文、项目导读、片段数、原页更新时间、取得时间、过期状态和许可。原 `indexed_pages`、`source_chunks`、`coverage` 仍只描述私有课程资料；离线云端不能报告成已连通私有全文索引。

文本为空不能自动判定该页没有知识，因此仍保留原页检查提示。这里只读取 PDF 文本层，没有进行 OCR，也未确认这些页全部是扫描页。自动提取的公式、表格、页内顺序仍需要对照原图核查。

## 上下文预算与供应商缓存

聊天输入框底部提供模型、上下文、更多和发送；主问答与“小航”共用选择。上下文档位为 4K、8K、16K、32K、64K、128K，自动取 32K。服务端实际组装并检查输入：保留系统规则和完整当前问题，按预算删去较早的完整对话轮次、较低优先级资料或模板，并报告是否截短；必要内容放不下时返回错误，不自动付费调用模型压缩。

估算方法是 UTF-8 文本字节数加消息/工具封装开销的保守上界，并预留 1024 余量；不是供应商 tokenizer 的精确测量。记录估算输入、保留/省略历史、证据数与裁剪状态；供应商提供 `usage` 时再记录实际输入和缓存命中，未提供为 `null`。多轮 Agent 的用量字段描述最后一次供应商请求，不作为整个任务累计计费。

输入预算不会改变模型原生上下文窗口，也不会指定供应商的 KV cache 大小。DeepSeek 的重复前缀缓存由供应商处理且不保证命中；百炼区分隐式与显式缓存，具体支持模型、生命周期和费用以官方文档为准。本项目没有创建显式缓存、缓存管理服务或承诺固定缓存命中率。依据：[DeepSeek 官方缓存说明](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)、[阿里云百炼官方缓存说明](https://help.aliyun.com/zh/model-studio/context-cache)。

输入区的模型切换与配置入口参考 [WorkBuddy 官方模型配置](https://www.codebuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)和[任务上下文说明](https://www.codebuddy.cn/docs/workbuddy/Create-Task)，没有移植该产品或声称实现其完整 Agent。

这些框架不能凭空增加海洋知识。增加知识仍需有来源的教材、论文、技术文档与数据说明进入索引，检索到正确片段，并在回答中核查适用条件。本项目未运行上述完整框架的比较基准，不声称自身检索优于它们。

## 尚未接入的扩展

向量模型与重排模型可改善同义改写和跨语言召回，但目前未部署；中文查询英文原文依赖课程术语表或公开主题的人工标题、别名和导读。扫描页可接 Docling 或本地 OCR，再核查公式与单位，目前只报告缺口。官方清单文档刷新已经实现；实时观测 API 与通用全网搜索尚未接入。维护者可继续登记获授权资料，匿名访客不能改写全组知识库，知识也不会永久写入供应商模型。

后续评测应覆盖原先已有知识点、新导入页的概念、不同海域条件、单位误用、资料冲突及完全无关问题，同时检查来源页是否真实支持回答。扩大页数只是扩大可检索范围，不等于训练成功或事实正确率保证。
