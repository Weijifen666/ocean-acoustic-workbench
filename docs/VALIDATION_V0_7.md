# v0.7 验收记录

日期：2026-10-15。本项目仅用于课程作业，无任何商业用途。

## 本轮变更

- 采用 Fuwari 的 MIT 卡片样式并改为海洋配色；Sakana Widget 使用 core 入口和项目原创透明角色图，未使用其默认版权角色。模型、上下文和发送位于输入框底部。
- 回答支持 Markdown、GFM 表格、KaTeX、MATLAB 代码高亮与复制。云端使用供应商 SSE 增量；停止会中止上游，半途断流不会记录为完成。供应商输出上限或内容过滤有明确状态。
- D1 增量迁移 0002、0003：配置与消息分别加密保存；独立会话、旧记录惰性迁移、请求幂等、完成事务和取消竞态保护。保留原 0000、0001 SQL 与快照。
- Sites 平台账户个人空间跨设备使用同一身份；匿名浏览器空间独立保留。共享课题只有明确加入的成员可访问，笔记由用户主动保存；个人 Key 和私人会话不进入课题。邀请一次使用、24 小时有效、可撤销，数据库只保存邀请哈希。
- 本地 SQLite 耐久队列、单执行器锁、重启恢复和显式中断处理；重复提交返回原任务。自然语言只提取固定 Munk 模板参数草案，确认后才提交计算；支持受控实验比较。
- 文本入库 v2 保留原始 Unicode；NFKC 只用于检索。口语与中英术语规则、多路 RRF、课程概念卡优先和时空数值证据门控已接入两端。

## 仍有边界

版本 10 修复了真实界面暴露的检索精度问题：Munk 剖面仅保留 K016、S17 第375/376页原文及两张关联卡，不把同姓作者、目录、Cox–Munk 海面模型或泛剖面网页填入剩余位置；明确点名 World Ocean Atlas 时保留对应公开导读。Cox–Munk-only 查询从完整语料统计 BM25 后仅选命名原文，实际定位到 S18 第400页。无 Key 展示简短课程卡/项目导读及定位，原文留在抽屉，Munk 正文约220字。新增9项精度/格式回归，检查的是已标注规则允许候选，不是逐句语义支持率。

实际4101索引的60题复测仍有一个保守门控与题签差异：K50“World Ocean Atlas是今天的海温吗”被现有隐含数值规则判为缺少观测数据；全部路由匹配59/60。检索目标题召回、来源定位与节点召回为1，不能因此宣称所有问答都正确。题集用于开发，仍需独立盲测和真实模型答案审查。

MATLAB 与私有原文检索仍由项目电脑通过主动 HTTPS 桥接提供，电脑关机后该部分不可用。云端图谱、内置公开索引和已配置的模型问答可独立工作。网页不能直接读写任意访客本地工程；未开放任意代码执行。

目前没有通用实时全网搜索、实时 Argo/海况数值接口、向量检索、神经重排、OCR、LLM 自动抽图或模型训练。网页快照日期不能当作观测时间；候选引用与编号合法性检查不能代替逐条语义支持验证。新的真实供应商生成、正式账户跨设备登录仍需相应账户与额度验收，不用无效 Key 的认证结果冒充成功生成。
