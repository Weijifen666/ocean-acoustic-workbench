## 当前架构的真实部署位置

本项目在本轮修改之前已经有公网网页和云端模型问答，并非只有 `127.0.0.1` 页面。已发布基线可参见 [v0.6 验收记录](VALIDATION_V0_6.md)；本轮新增代码的最终生产状态以文末验收栏为准。

| 部分 | 当前放置位置 | 能力与依赖 |
| --- | --- | --- |
| 网页界面、图谱、模型目录 | 公网托管站点 | 其他设备可以访问；页面可打开不等于计算节点在线 |
| 模型请求与已提供的云端检索 | 云端 Worker | 使用当前用户自己的供应商配置；真实模型调用还取决于有效密钥、额度和模型权限 |
| 模型配置、对话等持久数据 | 云端 D1，加密保存相关正文 | 本轮新增索引化对话、平台登录账户空间与共享课题；须完成迁移和生产验证后确认实际效果 |
| 已提供的教材页面图片缓存 | 云端 R2；首次生成可能依赖节点 | 缓存不等于已经上传全部原教材；不能据此承诺节点离线时全部原页都可读取 |
| MATLAB R2024a、AT、KRAKEN/FIELD | 项目维护者的本地 Windows 计算节点 | 访客无需安装 MATLAB，但维护者节点必须联网、运行且不休眠 |
| 原始教材与私有全文索引 | 本地节点的私有运行目录 | 原 PDF 与完整文本层检索仍依赖本机；原资料不随 GitHub 源码公开分发 |
| 云端到节点通信 | 节点主动发起的加密 HTTPS 桥接 | 连接中断会影响节点功能；不是把 MATLAB.exe 部署进了云端 Worker |

因此，目前是“公网前端与云端问答 + 本地计算/私有资料节点”的混合架构，**尚非脱离本机也能独立完成 MATLAB 仿真的全云系统**。源码开源、网页托管和计算节点迁移是三个不同的步骤。

## 本轮代码改进及其验证边界

- 本地任务队列改为 SQLite 持久领取，保留作业与状态事件；升级前备份，重启中断不误报成功。遗留运行任务会触发明确的中断与队列暂停处理。
- 公网提交使用访客派生的命名空间和幂等标识。重复提交优先恢复已接受任务，不因网络重试额外计算；不确定的提交需核对本地只读 receipt，不能仅凭 pending 行绕过队列限额。
- 自然语言入口只解析明确参数和单位，列出缺参、假设及未支持请求；预览和人工确认后才由固定 Munk 模板提交计算，不开放任意代码公网执行。
- 已有结果对比只读取真实产物，核对环境、坐标、单位、归一化与哈希。可比不等于已经证明求解器收敛或真实海域准确性。
- 共享课题仅保存明确提交的研究笔记及来源链接，个人模型配置不自动共享，来源链接不由该接口抓取。单次邀请、有效期、撤销、成员隔离及加密使用隔离测试验证；本轮没有代用户真实创建团队或发送邀请。
- 教材与公开网页快照只提供候选依据；时间、海域和深度相关的实测数值需要匹配观测记录。当前没有因为网页刷新就接入实时海况数据，也没有进行模型训练。

上述功能已进行相应离线、临时数据库和模拟响应检查；不能把这些测试写成新版本真实 MATLAB 计算、真实付费模型调用或多设备登录的生产验收结果。旧版本真实成功作业也不能替代新版本计算回归。
