# 地图选点的数据与显示验收

问题：地图选点后只看到标记，用户无法找到剖面。实际原因是结果曲线与表格排在整张地图之后，成功和错误没有在选点旁提示；原滚轮事件又阻止页面滚动、改成地图缩放，使结果更难发现。

## 在线数据核查

主站与独立数据站的 `/api/ocean-data` 均返回 `available=true`、`storage=cloud`、`requires_local_data=false`，版本为 `woa18-etopo1-v1`。状态报告17个时期、13,985个对象、2,308,803,300字节；发布记录为11月1日全量校验激活。数据查询由线上Worker读取云端R2数据块，不依赖访问者的本地资料、Python、MATLAB或计算节点。

本次实际请求108次：两个站点各查询3个地点的全部17期剖面，共102条剖面；另查两种地形视野及错误版本。剖面全部HTTP 200，数值有限、深度递增，两站结果逐项相同。没有重新扫描全部云端对象，也不代表已逐点验证全球覆盖。

## 显示修复与验证

地图旁新增当前选点状态卡：加载、错误与成功显示在相同位置；成功列出请求点、实际格点、时期、有效层、水深、有效深度及海表温盐声速。表面缺测不会把其他深度当作海表。完整表格、曲线、CSV/JSON和仿真草案保留，由用户点击“查看完整剖面与下载”定位结果，选点不自动抢走地图视野。

普通滚轮恢复页面滚动，Ctrl加滚轮才缩放地图；地图仍支持按钮、键盘与拖动。触屏纵滑保留页面滚动，横拖平移。坐标输入草稿与实际提交选点分开，未提交输入不再移动已选标记。

15项海洋数据/UI测试、两端构建通过。实际浏览器验证了原界面数据位于地图下方、新概要显示、加载状态、地图点击联动、用户按钮滚到完整曲线/表格，以及普通滚轮滚动时地图范围保持不变。真实触摸设备手势未另验，不用纯事件测试冒充手机实测。
