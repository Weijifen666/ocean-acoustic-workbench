# 海洋声学工作台 · 公网版 v0.3

公开网址：https://ocean-acoustics-workbench-30682.jovial-sun-4182.chatgpt.site

无需账号或软件安装。课程图谱包含 6 个单元、46 个知识点和 126 条关系，支持目录、关联查询、学习路径、原理图及教材原页片段。模型目录包括 DeepSeek、阿里云百炼、Moonshot Kimi、智谱 GLM 的 16 个具体预设；调用云端模型需填写访客自己的供应商 API Key。

## 运行方式

React 页面和图谱数据由云端 Worker 托管，D1 保存加密的临时请求，R2 保存加密响应及公开教材图片缓存。Windows 计算节点通过 HTTPS 主动轮询请求，再交给受限访客网关处理；没有把本机管理接口暴露到公网，也不依赖临时隧道地址。

网关为每个浏览器签发随机 HttpOnly/Secure Cookie。模型配置、对话和仿真任务均按访客隔离；公共 Agent 仅阅读课程公开模板。API Key 不返回前端，不保存在发布源码中，只在节点内存中保留。更换浏览器或设备会建立新的访客空间。浏览器清除 Cookie 后不能找回旧任务，当前版未实现跨设备账号同步。

MATLAB 使用项目电脑上已安装的 R2024a 和 AT 求解器。每批最多 4 组，同时保留最多 16 组排队/运行任务；同一访客上一批未完成时不能重复提交。公开版只运行经校验的 Munk/KRAKEN/FIELD 模板，不执行任意上传代码。

## 计算节点

运行相邻本地项目中的 `ocean-acoustic-workbench/start-public.ps1` 可启动本地后台、访客网关和云端连接程序。电脑必须联网并保持运行；关机或休眠会中断仿真和当前模型连接。静态图谱、关联查询、模型目录及已缓存的教材图片仍由云端提供。节点重启后，各访客需重新填写模型密钥；任务记录保留在本地数据库。

## 构建和发布

`npm ci` 后运行 `npm run build`，生成 `dist/server/index.js`。源码及 Drizzle 数据库迁移通过 Sites 标准流程推送、打包、保存版本并公开发布。`.openai/hosting.json` 仅保存项目身份及 DB/BUCKET 逻辑绑定；网关密钥只配置为云端运行时 secret，并留在本地项目未入库的 `.local/public-runtime.json`。

已通过实际公网验证：匿名访问、访客 Cookie 隔离、共享模板读取、管理接口拒绝、课程知识卡检索、教材 PNG、真实 MATLAB 作业、声场图/曲线及结果 ZIP 下载。未配置真实供应商 API Key，因此尚未验证真实付费模型调用。
