公开网址：[海洋声学工作台](https://ocean-acoustics-workbench-30682.jovial-sun-4182.chatgpt.site/)。无需注册或在访问设备安装 MATLAB；课程图谱和公开资料可直接点击查看，无需 API Key。调用供应商模型需要访客自己的有效 Key、额度和模型权限。

## 聊天与资料

公共网页与本地管理前端共用 Fuwari 风格改编界面、主问答、“小航”和输入框控件：模型、上下文、更多、发送。Sakana 动画核心驱动原创透明海洋研究员插画；未使用上游默认动漫角色或官方 Logo。样式与动画核心保留 MIT 许可，说明和完整许可见 `src/vendor/`。

模型切换复用本人已配置供应商的 Key，并保存每条回答的请求/响应模型。默认“资料 + 模型知识”（`general`），在“更多”可改为“仅依据资料”（`course`）；资料外的模型一般知识单列说明，不编造资料引用。缺口记录属于个人，不自动进入共享知识库或训练模型。

公网聊天使用真实 SSE 供应商文本增量，支持停止；非完整连接不冒充完整答案，供应商输出上限或内容限制会返回截断状态。独立对话分开保存历史，完成的交流以加密消息行持久化；重试请求通过幂等标识避免重复生成和重复消息。没有模型 Key 时仍可查看课程卡和公开来源。

输入预算支持 4K、8K、16K、32K、64K、128K，自动 32K。云端与 Python 实际组装并检查发送内容，按预算减少历史/资料、记录裁剪情况；当前问题和必要系统规则放不下时返回错误。计数为保守 UTF-8 上界估算，供应商返回的实际输入与缓存命中另记，未知为 `null`。这些档位不是模型原生窗口或供应商 KV cache 的大小，也没有调用模型压缩来冒充预算控制。

课程图谱为6个单元、46个知识点和126条有类型关系。节点在线时可检索五份授权资料的1789 / 1846页、4101个私有片段；57页空/短文本待复核，未做 OCR。入库格式2保留显示原文的 Unicode，NFKC 仅供检索，旧索引需从原文件重建才能恢复已损失字符。私有原文不上传 GitHub，节点离线时明确说明不可用。

公开索引已实际接入 30 篇 NOAA NOS 正文和 9 条项目自写中文导读，共 39 个可检索来源、67 个片段。42 项登记中的 3 项仅为动态数据入口，尚未取得实时值。酸化、珊瑚、海平面、海流、漂流浮标、海啸和质控等中文问题可召回英文官方正文或明确标记的项目导读。图谱“学习资源”可直接查看机构、URL、原页更新时间、取得时间、哈希和许可；导读不是官方译文或复制原文。

BM25/双语别名结合有语境的口语拆问和真实 RRF，保留精确课程概念及其条件；未接付费向量或神经重排。引用标记为候选，不代表回答命题已经证明。指定时间、海域和深度的数值请求缺少匹配观测时返回资料缺口，即使选择一般知识模式也不编造实测值。60题开发回归与边界见 [KNOWLEDGE_QUALITY.md](../docs/KNOWLEDGE_QUALITY.md)，不能把召回指标称为100%回答准确率。

## 个人空间与小组课题

匿名访问使用随机 HttpOnly/Secure Cookie；更换浏览器、设备或清除 Cookie 会得到新的匿名空间。通过 Sites 平台登录后，个人会话和配置绑定本站下的账户，可在同一账户的设备间访问。应用不收集平台密码，登录时不自动合并匿名历史或模型 Key。

四人小组可登录后新建课题，由创建者生成邀请，队员登录并接受后共享明确提交的研究笔记与来源链接。邀请有有效期并可撤销；成员不能因此读取他人的模型 Key、私人对话、教材索引或任意本地文件。共享课题不会自动公开任务产物或把笔记当作已核实知识；代码修改仍通过 GitHub 协作。

## 运行方式与边界

React 页面、课程卡与公开知识 JSON 由云端 Worker 托管，模型请求由云端直接发送给供应商。D1 加密保存个人配置、独立会话和研究笔记；课题成员权限单独检查。云端连接使用 D1 请求队列和 R2 加密响应/公开结果缓存。Windows 计算节点主动发起 HTTPS 请求并调用受限访客网关，不开放本机管理端的公网入站接口。

Key 不以明文返回浏览器或写入源码，可清除本人全部模型密钥；课题不共享这些 Key。公共 Agent 只分析课程模板与明确提供的资料，不操纵访问设备本机 MATLAB，不执行任意上传代码。

MATLAB 由计算节点获授权的 R2024a 与 AT KRAKEN/FIELD 执行，仅支持固定 Munk 模板。自然语言草案只解析显式参数和单位并列出缺项，需用户预览、确认后提交，不会自动启动计算。每批最多4组，同时最多16组排队/运行；同一访客上一批未完成不能重复提交。稳定幂等标识避免网络重试重复计算。

节点队列、批次和状态事件存入 SQLite。重启保留待执行任务；孤立运行任务标记中断并暂停，管理员确认残留进程后恢复，不自动重跑未知状态的 MATLAB。可对2–4个成功任务核查环境、网格与产物后做结果对比。节点离线时仿真与私有全文检索不可用，云端图谱、公开快照和已配置模型问答仍可用。

节点启动与状态查询在后台按 168 小时 TTL 检查官方白名单文档，带线程锁、超时/大小限制与安全重定向检查，失败保留最后成功快照。默认只写独立私有 `.local/kb/open-ocean/snapshot.json`，不覆盖教材数据库。云端包离线使用构建时快照，维护者通过导出、构建发布更新；这不是实时全网搜索。CO-OPS、NDBC、热含量入口仍未接通数据 API，不能把介绍页或历史示例说成最新海况。参见 [公开知识说明](../docs/OPEN_OCEAN_KNOWLEDGE.md)。

尚未实现 OCR、模型训练、向量检索、实时观测接入、通用全网搜索或任意代码 Agent。知识不会永久写入供应商模型；运行成功与图像好看不构成物理验证。
