公开网址：[海洋声学工作台](https://ocean-acoustics-workbench-30682.jovial-sun-4182.chatgpt.site/)。无需注册或在访问设备安装 MATLAB；课程图谱和公开资料可直接点击查看，无需 API Key。调用供应商模型需要访客自己的有效 Key、额度和模型权限。

## 聊天与资料

公共网页与本地管理前端共用主问答、“小航”和输入框控件：模型、上下文、更多、发送。模型切换复用已配置供应商的 Key，并保存每条回答的请求/响应模型。默认“资料 + 模型知识”（`general`），在“更多”可改为“仅依据资料”（`course`）；资料外的模型一般知识单列说明，不编造资料引用。缺口记录只属于当前访客，不自动进入共享知识库或训练模型。

输入预算支持 4K、8K、16K、32K、64K、128K，自动 32K。云端与 Python 实际组装并检查发送内容，按预算减少历史/资料、记录裁剪情况；当前问题和必要系统规则放不下时返回错误。计数为保守 UTF-8 上界估算，供应商返回的实际输入与缓存命中另记，未知为 `null`。这些档位不是模型原生窗口或供应商 KV cache 的大小，也没有调用模型压缩来冒充预算控制。

课程图谱仍为 6 个单元、46 个知识点和 126 条有类型关系。节点在线时可检索五份授权资料的 1789 / 1846 页、4092 个私有片段；57 页空/短文本等待复核，尚未进行 OCR。私有原文不上传 GitHub，节点离线时明确说明不可用。

公开索引已实际接入 30 篇 NOAA NOS 正文和 9 条项目自写中文导读，共 39 个可检索来源、67 个片段。42 项登记中的 3 项仅为动态数据入口，尚未取得实时值。酸化、珊瑚、海平面、海流、漂流浮标、海啸和质控等中文问题可召回英文官方正文或明确标记的项目导读。图谱“学习资源”可直接查看机构、URL、原页更新时间、取得时间、哈希和许可；导读不是官方译文或复制原文。

## 运行方式与边界

React 页面、课程卡与公开知识 JSON 由云端 Worker 托管，模型请求由云端直接发送给供应商。D1 按访客加密保存模型配置、对话和缺口记录；云端连接还使用 D1 请求队列和 R2 加密响应/公开结果缓存。Windows 计算节点主动发起 HTTPS 请求并调用受限访客网关，不开放本机管理端的公网入站接口。

随机 HttpOnly/Secure Cookie 标识访客。Key 不返回浏览器或写入源码，可在模型页清除全部密钥；更换浏览器、设备或清除 Cookie 会建立新访客空间，当前没有账号登录与跨设备历史同步。公共 Agent 只读取课程模板，不操纵访问设备本机 MATLAB，也不执行任意上传代码。

MATLAB 由计算节点已安装、获授权的 R2024a 与 AT KRAKEN/FIELD 执行，当前只支持校验过的 Munk 模板。每批最多 4 组，同时最多 16 组排队/运行任务；同一访客上一批未完成不能重复提交。节点关机、休眠或离线会停止仿真与私有全文检索，云端图谱、公开快照和已配置模型问答仍可用。

节点启动与状态查询在后台按 168 小时 TTL 检查官方白名单文档，带线程锁、超时/大小限制与安全重定向检查，失败保留最后成功快照。默认只写独立私有 `.local/kb/open-ocean/snapshot.json`，不覆盖教材数据库。云端包离线使用构建时快照，维护者通过导出、构建发布更新；这不是实时全网搜索。CO-OPS、NDBC、热含量入口仍未接通数据 API，不能把介绍页或历史示例说成最新海况。参见 [公开知识说明](../docs/OPEN_OCEAN_KNOWLEDGE.md)。
